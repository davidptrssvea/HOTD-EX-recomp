# HOTD EX Local Builder v1.0.1

The main menu now checks GitHub for a newer stable version. Choose **Updates** to read the release notes and decide whether to install.

Setup verifies the download and builds in a separate folder from your installed arcade dump. It installs the new launcher and runtime, retains preferences and cabinet saves, and reopens the menu. The update folder keeps the Setup log and a backup of the files it replaced.

To get the updater the first time, extract this builder and run **Setup.cmd** with your supported dump and existing installation folder. Later releases can be installed from the menu.
